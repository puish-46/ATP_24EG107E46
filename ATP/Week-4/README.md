# Week 4 – HTML Fundamentals

## Overview

This week introduces the core building blocks of web development — HTML for page structure. Three progressively complex web pages demonstrate headings, paragraphs, lists, links, images, and semantic elements.

---

## Folder Structure

```
Week-4/
├── basicWebpage.html              # Basic HTML elements demo
├── nestedUnorderedList.html       # Nested list with food categories
├── pochiTheCat.html               # Mini profile page with image and links
└── README.md
```

---

## Programs

| # | File | Description | Key Concepts |
|---|------|-------------|--------------|
| 1 | `basicWebpage.html` | Simple page with heading, paragraphs, anchor link, and an unordered list | `<h1>`, `<p>`, `<a>`, `<ul>`, `<li>`, semantic HTML |
| 2 | `nestedUnorderedList.html` | Nested unordered list showing food categories (fruits, vegetables, cereals, nuts) | Nested `<ul>`, `<li>`, heading hierarchy |
| 3 | `pochiTheCat.html` | A mini cat profile page with image, ordered list, external links, and footer | `<img>`, `<ol>`, `<a target>`, `<hr>`, `<header>`, `<main>`, `<footer>` |

---

## Concepts Covered

- **HTML Document Structure** — `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- **Semantic HTML** — `<header>`, `<main>`, `<section>`, `<footer>`
- **Headings & Paragraphs** — `<h1>` to `<h2>`, `<p>`
- **Lists** — Ordered (`<ol>`), Unordered (`<ul>`), and Nested lists
- **Links** — `<a href="">` with `target="_blank"` and `rel="noopener noreferrer"`
- **Images** — `<img>` with `src`, `alt`, and `width`
- **Horizontal Rule** — `<hr>` for visual section dividers
