# Week 4 - HTML Basics

## Overview

This week introduces the basics of HTML — the building block of web pages. Covers essential tags, page structure, lists, links, images, and basic CSS styling.

## Concepts Covered

- **HTML Document Structure** — `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- **Headings & Paragraphs** — `<h1>` to `<h3>`, `<p>`
- **Lists** — Ordered (`<ol>`), Unordered (`<ul>`), and Nested lists
- **Links** — `<a href="">` anchor tags
- **Images** — `<img>` tag with `src` and `alt`
- **Horizontal Rule** — `<hr>`
- **CSS Linking** — External stylesheet using `<link>`
