# HTML Tables

## Overview

Builds and styles HTML tables using CSS. Covers basic table structure and custom styling.

## Files

| File | Description |
|------|-------------|
| `index.html` | HTML page with styled tables |
| `styles.css` | CSS styles for table, rows, and headers |

## Concepts Covered

- **Table Tags** — `<table>`, `<tr>`, `<th>`, `<td>`, `<thead>`, `<tbody>`
- **Table Styling** — borders, padding, background colors
- **CSS Selectors** — targeting table elements
