# Week 5 – CSS, Tailwind & React Basics

## Overview

This week covers HTML tables, CSS Flexbox for layouts, Tailwind CSS utility classes, and an introduction to React — including components, props, and rendering lists.

---

## Folder Structure

```
Week-5/
├── htmlTables/             # Styled HTML tables using CSS
├── cardsUsingFlex/         # Card layout built with CSS Flexbox
├── tailwindProjects/       # Pages built using Tailwind CSS
├── productWithReact/       # Product listing app using React + Vite
├── userlistWithReact/      # User list app using React components
└── README.md
```

---

## Sub-Projects

| # | Folder | Description | Key Concepts |
|---|--------|-------------|--------------|
| 1 | `htmlTables/` | Multiple styled HTML tables — employee, student marks, expenses, grades | `<table>`, `rowspan`, `colspan`, `<thead>`, `<tbody>`, CSS styling |
| 2 | `cardsUsingFlex/` | Card layout with navigation bar and 4 image cards | `display: flex`, `justify-content`, `gap`, `box-shadow` |
| 3 | `tailwindProjects/` | Three pages built entirely with Tailwind utility classes | Tailwind CSS, responsive breakpoints, grid layout |
| 4 | `productWithReact/` | Product listing app rendering cards from data | React components, props, `.map()`, data separation |
| 5 | `userlistWithReact/` | User list app with navigation, user cards, and footer | Component composition, props, reusable components |

---

## Concepts Covered

- **HTML Tables** — rows, columns, headers, `rowspan`, `colspan`, styling
- **CSS Flexbox** — `display: flex`, alignment, gap, card layouts
- **Tailwind CSS** — utility-first styling, responsive design
- **React** — components, props, JSX, mapping arrays
- **Modularity** — separating data from components, reusable component patterns
