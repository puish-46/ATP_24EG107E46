# Week 5 - CSS, Tailwind & React Basics

## Overview

This week covers HTML tables, CSS Flexbox for layouts, Tailwind CSS utility classes, and an introduction to React — including components, props, and rendering lists.

## Concepts Covered

- **HTML Tables** — rows, columns, headers, styling
- **CSS Flexbox** — card layout using `display: flex`
- **Tailwind CSS** — utility-first styling
- **React** — components, props, JSX, mapping arrays

## Sub-Projects

| Folder | Description |
|--------|-------------|
| `HTML_tables/` | Styled HTML tables using CSS |
| `Cards_using_flex/` | Card layout built with CSS Flexbox |
| `tailwind_projects/` | Pages built using Tailwind CSS |
| `Product_with_react/` | Product listing app using React + Vite |
| `Userlist_with_react/` | User list app using React components |
