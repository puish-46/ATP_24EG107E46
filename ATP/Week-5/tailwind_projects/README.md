# Tailwind CSS Projects

## Overview

Multiple web pages built using Tailwind CSS utility classes. Covers layout, typography, and component styling without writing custom CSS.

## Files

| File | Description |
|------|-------------|
| `src/hello.html` | Basic Tailwind page |
| `src/city_guide.html` | City guide page styled with Tailwind |
| `src/Libertarians.html` | Content page using Tailwind utilities |
| `src/input.css` | Tailwind base input file |
| `output.css` | Compiled Tailwind CSS output |

## Concepts Covered

- **Tailwind Utility Classes** — spacing, colors, typography, layout
- **Responsive Design** — using Tailwind breakpoints
- **Tailwind CLI** — compiling `input.css` to `output.css`
