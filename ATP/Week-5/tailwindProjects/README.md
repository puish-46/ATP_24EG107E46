# Tailwind CSS Projects

## Overview

Multiple web pages built using Tailwind CSS utility classes. Covers layout, typography, responsive design, and component styling without writing custom CSS.

## Files

| File | Description |
|------|-------------|
| `src/hello.html` | Basic Tailwind page with hero, 3-column grid, and footer |
| `src/cityGuide.html` | City guide page with nav, hero image, and content grid |
| `src/libertarians.html` | Responsive political content page with dark theme |
| `src/input.css` | Tailwind base input file |
| `output.css` | Compiled Tailwind CSS output |

## Concepts Covered

- **Tailwind Utility Classes** — spacing, colors, typography, layout
- **Responsive Design** — using Tailwind breakpoints (`sm:`, `md:`, `lg:`)
- **Grid Layout** — `grid-cols-3`, responsive column changes
- **Tailwind CLI** — compiling `input.css` to `output.css`
