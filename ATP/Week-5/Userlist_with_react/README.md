# User List - React App

## Overview

A React app that displays a list of users using multiple components. Includes Navigation, User card, User list, and Footer components.

## Project Structure

```
src/
├── App.jsx                  # Root component
├── components/
│   ├── Navigation.jsx        # Top navigation bar
│   ├── Userlist.jsx          # Renders list of users
│   ├── User.jsx              # Single user card
│   └── Footer.jsx            # Footer component
└── main.jsx                  # Entry point
```

## Concepts Covered

- **React Components** — multiple reusable components
- **Props** — passing user data down to components
- **Component Composition** — combining Nav, List, Footer
- **Array Mapping** — rendering user list with `.map()`
- **Vite** — React project setup
