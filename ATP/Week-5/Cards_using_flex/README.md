# Cards Using Flexbox

## Overview

A simple card layout built with HTML and CSS using Flexbox. Displays a navigation bar and a row of image cards.

## Files

| File | Description |
|------|-------------|
| `index.html` | Card layout with nav and 4 image cards |
| `styles.css` | Flexbox styles for nav and card grid |

## Concepts Covered

- **CSS Flexbox** — `display: flex`, alignment, gap
- **Navigation Bar** — styled with flex
- **Card Component** — image, heading, paragraph per card
