# Week 1 - JavaScript Basics

## 📌 Overview

This week covers the fundamentals of JavaScript programming including variables, conditional statements, loops, functions, and array/object manipulation.

---

## 📁 Files

| File | Description |
|------|-------------|
| `Biggest_of_two_numbers.js` | Compares two numbers and prints the biggest using `if-else` |
| `Biggest_of_three_numbers.js` | Compares three numbers and prints the biggest using `if-else if-else` |
| `function_for_biggest_number.js` | Finds the biggest number using a reusable function |
| `sum_of_marks.js` | Calculates the sum of student marks |
| `smallest_element_in_array.js` | Finds the smallest element in an array |
| `function_sum_of_array.js` | Returns the sum of all elements in an array using a function |
| `function_return_index_from_array.js` | Arrow function that searches for an element and returns its index |
| `Employees.js` | Works with an array of employee objects — insert, delete, and update operations |

---

## 🧠 Concepts Covered

- **Variables** – `let`, `const`
- **Conditional Statements** – `if`, `else if`, `else`
- **Loops** – `for` loop
- **Functions** – Regular functions and Arrow functions (`=>`)
- **Arrays** – Traversal, search, min/max finding
- **Objects** – Creating and manipulating objects inside arrays
- **Array Methods** – `splice()` for insert and delete operations

---

## 🔍 Key Programs

### 1. Biggest of Three Numbers
Compares three values using nested `if-else if-else` conditions.

### 2. Search Element in Array (Arrow Function)
Uses an arrow function to loop through an array and return the **index** of the found element, or `"not found"` if it doesn't exist.

### 3. Employee Management (Objects & Arrays)
- Stores employee data (ID, name, marks) as an array of objects
- **Inserts** a new employee at position 2 using `splice()`
- **Removes** an employee by name using a `for` loop + `splice()`
- **Updates** the last mark of a specific employee

---

## 🛠️ How to Run

Make sure **Node.js** is installed. Then run any file using:

```bash
node filename.js
```

**Example:**
```bash
node Employees.js
node function_return_index_from_array.js
```
