# Week 1 – JavaScript Fundamentals

## Overview

This week covers core JavaScript programming concepts including variables, conditional logic, loops, functions (declarations, expressions, arrow functions), and array/object manipulation with CRUD operations.

---

## Programs

| # | File | Description | Concepts Used |
|---|------|-------------|---------------|
| 1 | `biggestOfTwoNumbers.js` | Compares two numbers and prints the larger one | Variables, `if-else` |
| 2 | `biggestOfThreeNumbers.js` | Compares three numbers and prints the largest | Variables, `if-else if-else` |
| 3 | `findBiggestNumber.js` | Finds the biggest of three numbers using a reusable function | Function declaration, `return` |
| 4 | `searchElementIndex.js` | Searches for an element in an array and returns its index | Arrow function, `for` loop, `===` |
| 5 | `arraySum.js` | Calculates the sum of all elements in an array | Function expression, `for` loop |
| 6 | `smallestElementInArray.js` | Finds the smallest element in a marks array | Array traversal, comparison |
| 7 | `sumOfMarks.js` | Computes the total of all marks in an array | Array, `for` loop, accumulator pattern |
| 8 | `employeeCrud.js` | Performs insert, update, and delete on an array of employee objects | Array of objects, `splice()`, `===` |

---

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run any program with:

```bash
node <filename>
```

**Example:**

```bash
node biggestOfTwoNumbers.js
```

---

## Concepts Covered

- **Variables** – `let`, `const`
- **Conditional Statements** – `if`, `else if`, `else`
- **Loops** – `for` loop for array traversal
- **Functions** – Declaration, Expression, Arrow functions
- **Arrays** – Indexing, traversal, accumulation
- **Objects** – Array of objects, property access
- **Array Methods** – `splice()` for insert, update, and delete
