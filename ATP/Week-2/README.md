# Week 2 - Advanced JavaScript & Node.js Basics

## Overview

This week covers advanced JavaScript concepts like spread/rest operators, shallow and deep copy, promises, and async patterns. It also includes two mini projects — a Task Management module and a REST API backend using Express.

## Concepts Covered

- **Spread & Rest Operators**
- **Shallow Copy & Deep Copy**
- **Promises**
- **setTimeout / setInterval**
- **Array & Object Manipulation**
- **Node.js with Express**
- **REST APIs (GET, POST, PUT, DELETE)**
