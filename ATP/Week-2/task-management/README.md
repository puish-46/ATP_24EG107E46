# Task Management Module

## Overview

A simple task management module built with JavaScript. It validates task input before adding tasks to the list.

## Files

| File | Description |
|------|-------------|
| `task.js` | Core logic — add, get, and complete tasks |
| `validator.js` | Validates title, priority, and due date |
| `app.js` | Entry point — calls task functions |

## Concepts Covered

- **ES Modules** (`import` / `export`)
- **Input Validation**
- **Modular Code Structure**

## How to Run

```bash
node app.js
```
